# Contributing
Read AGENTS.md and the development guide. Establish a baseline, implement a
bounded ticket, add accepted/rejected behavior tests and record actual evidence.
Preserve the fixed stack, strict types and historical handoff. Use ADRs for shared
contract/architecture changes. Do not commit secrets or generated dependencies.
The owner has not selected a product/contribution license; do not relicense or
publish the application automatically. Third-party licenses remain applicable.
