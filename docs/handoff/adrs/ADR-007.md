# ADR-007 — Stable language-neutral contracts

**Status:** Accepted — protocol baseline
**Date:** 2026-10-08
**Owner:** founding technical/product lead

## Context
The product must combine a fast native collaboration experience with inspectable, bounded local/cloud execution. This decision narrows implementation ambiguity while preserving the user's fixed requirements. Read the linked domain/security specifications before treating a mechanism as complete.

## Decision
Use versioned JSON wire contracts with opaque IDs, bounded integer revisions/generations, RFC3339 timestamps, and decimal strings for large sequences and money micros. The supplied JSON Schemas govern structural validity and are mirrored into OpenAPI. Native and TypeScript serializers share valid/invalid golden fixtures. IPC is authenticated and locally scoped.

## Consequences and alternatives
Do not expose framework-internal data representations or language-specific error objects as permanent contracts. Schema validity does not imply authority. Numeric strings require exact arithmetic and canonicalization where hashed. Message rich text is a constrained AST, not arbitrary HTML. Major compatibility changes require an explicit migration window.

## Validation and revisit trigger
Gate: JSON Schema fixtures, OpenAPI mirror equality, Rust/TypeScript round trips, malformed frames, size limits, redacted structured errors, and skew tests. Action digests require a reviewed canonicalization design and golden byte vectors; a synthetic fixture digest is not an implementation.
