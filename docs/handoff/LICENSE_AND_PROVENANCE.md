# Provenance and licensing handoff

This package combines newly authored product specifications, original illustrative reference code, small original framework scaffolds, synthetic fixtures, and primary-source references. It does not redistribute third-party framework source packages, font files, customer data, or credentials. Upstream documentation is cited as evidence for assumptions, not incorporated as a copied product implementation.

Third-party dependencies retain their own licenses. GPUI licensing does not automatically cover other code in the Zed repository. The source register and dependency policy identify the checks required. Before distribution, choose an appropriate license for the actual product and any intentionally published runner/SDK, inventory all real resolved dependencies, and obtain an appropriate legal review for the business model. This handoff does not invent a project owner, copyright assignment, trademark clearance, or compliance opinion.

No final product brand is selected. “Human–Agent Workspace” is a descriptive working title. Do not ship using Slack, Zed, or another company's marks as the product name or imply affiliation. Preserve source attribution and any notices required for code actually adopted during implementation.
