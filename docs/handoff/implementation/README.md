# Implementation evidence workspace

This handoff contains no completed product tickets. Populate this directory as the build proceeds.

Copy `templates/PROGRESS_LEDGER.md` to `implementation/PROGRESS.md`. Place ticket evidence under `implementation/evidence/Txxx.md`, scenario evidence in `implementation/evidence/AT-xxx.md`, and actual recordings/logs under clearly labeled subdirectories. Do not commit credentials or real customer content. Reference-core test results belong to the handoff's `verification/` directory and do not automatically complete these implementation tickets.
