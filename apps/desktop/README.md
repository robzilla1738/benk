# Native GPUI desktop seed
Rust + GPUI shell with Inbox, Channels, Projects and Work navigation and a local,
clearly labeled task simulation. No Effect process is required for rendering.
Run `cargo run -p benk-desktop` after platform/toolchain setup.

This is not a completed client. Composer, accessible focus/semantics, persistence,
IPC, media, real identities and production review controls are unimplemented.
The canned second reviewer is a fixture. Native compilation and visual QA were
not performed in this package's preparation environment. Start BENK-001.
